## Summary

Create a slow, gap-driven intake path for Hevi Mala from `triage/`
while bracketing the synthetic relational-worlding corpus into one
triage-side catalog. The synthetic corpus includes Praxonic,
Navonic, Allovonic, and adjacent files. Those files are gathered into
one location of record and excluded from the first Hevi Mala source
pass.

## Motivation

The older worldbuilding material in `triage/` includes two different
kinds of source. One kind is the synthetic corpus: a body of coined,
relationality-derived worlding language that is valuable as archive
material but should not steer the first Hevi Mala intake. The other is
Hevi Mala itself: a fiction project with a strong setting, tonal
constraints, and project logic that can support a small published
batch now.

The repository already has a natural home for that work in
`personal/writing/fiction/`. A slow first pass should establish the
synthetic corpus as a bracketed catalog, physically consolidate the
Hevi Mala-specific triage files, and keep the published intake focused
on the non-synthetic Hevi Mala source pair.

## Steps

1. Maintain one catalog in `triage/` for the synthetic corpus. Record
   normalized titles, current paths, duplicate or variant copies, and a
   note explaining why each item is bracketed off.
2. Exclude the synthetic corpus from the Hevi Mala pilot source set,
   including the hybrid file `delta-register-praxonic-hevi-mala.md`.
3. Keep Hevi Mala-specific triage files consolidated in
   `triage/personal/writing/fiction/hevi-mala/`.
4. Re-author the published Hevi Mala batch from the consolidated
   non-synthetic source pair: `delta-register-hevi-mala-storyworld-
   guide.md` and `delta-register-hevi-mala.md`.
5. Publish only the minimum first batch: a project index, a core
   project text, a setting text, and project-internal expansions that
   are justified by the same source pair.
6. Add support pages in `media/`, `writing/`, or `games/` only if a
   concrete comprehension gap blocks the pilot. Do not import
   Praxonic, Navonic, or Allovonic vocabulary into those support pages.
